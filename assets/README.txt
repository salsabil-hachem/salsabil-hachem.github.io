HOW TO ADD YOUR MEDIA
Each project has a folder here: assets/<project-id>/
Drop files with these exact names and they appear on the project page automatically:
  photo-1.jpg  photo-2.jpg  photo-3.jpg  photo-4.jpg   -> photo gallery
  demo.mp4                                             -> video player
  report.pdf                                           -> report viewer + "Open report" button
Missing files are hidden, so the page never shows broken slots.
For the 3 featured projects (cdpr, kuka, twin), captions and file names are set
in the PROJECTS list at the bottom of index.html — edit them there.
Tip: keep photos under ~500 KB and videos under ~20 MB (GitHub limit is 100 MB per file).
